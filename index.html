نظام الأمن والتتبع (Security Audit System)

مشروع برمجي بلغة Python يهدف إلى إدارة مستخدمي نظام أمني، والتحقق من بياناتهم، وتسجيل جميع عمليات الدخول (Login) في سجل خاص (Logs).

مميزات النظام

    · نظام حماية (Login Gate):
  • لا يمكن الدخول للنظام إلا بمستخدم وكلمة مرور صحيحة.
  • · تحديد المحاولات: النظام يغلق بعد 4 محاولات دخول خاطئة (MAX_ATTEMPTS).
  • · التحقق من البيانات: يتأكد من صحة الإيميل، ورقم الهاتف (يقبل فقط بادئات يمنية محددة مثل 71, 73, 77, 78).
  • · إدارة المستخدمين: إضافة مستخدمين جدد مع تحديد صلاحياتهم (Access Level).
  • · سجل التتبع (Audit Logs): تسجيل كل محاولة دخول ناجحة أو فاشلة مع التاريخ والوقت.
  • · حفظ البيانات: استخدام ملفات نصية (data.txt و fixed_config.txt) لحفظ البيانات والإعدادات.

    • 🛠️ التقنيات المستخدمة:

    • · لغة البرمجة: Python
    • · بيئة التطوير: Visual Studio code
